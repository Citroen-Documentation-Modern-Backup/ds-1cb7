Figure : e5ab06it
[0188-T]
kit obturateurs
2. Dépose
IMPERATIF : Respecter les consignes de sécurité et de propreté spécifiques aux motorisations haute pression diesel injection (HDI) .
IMPERATIF : Pour toutes interventions sur le circuit d’additif, porter des lunettes de protection et des gants résistants aux hydrocarbures.
Mettre le véhicule sur un pont élévateur.
Figure : b1kg05pd
Déposer :
  • Les écrans aérauliques (1) (Sous caisse)
  • La sangle métallique (2)
Figure : b1kg04kd
ATTENTION : Obturer les orifices ; À l’aide de l’outil [0188-T].
Désaccoupler le raccord ( en "a").
Déconnecter : La pompe d’additif ( en "b").
Déposer les agrafes (3).
Figure : b1kg04ld
ATTENTION : Placer un lève-organe sous le réservoir à carburant, sur une surface d’appui adaptée.
ATTENTION : Lors de la dépose, ne pas retourner le réservoir d’additif (5).
Dépose : Réservoir d’additif (5) :
  • Déposer les écrous (4)
  • Descendre avec précaution le réservoir à carburant (Ne pas dépasser 5 centimètres)
  • Déposer le réservoir d’additif (5) (suivant flèche )
ATTENTION : En cas d’immobilisation prolongée du véhicule, Reposer les écrous (4).
3. Repose
ATTENTION : Respecter les couples de serrage .
Reposer :
  • Le réservoir d’additif (5)
  • Les écrous (4)
  • Les agrafes (3) (remplacer si nécessaire)
  • La sangle métallique (2)
Reconnecter : La pompe d’additif ( en "b").
Accoupler le raccord ( en "a").
Reposer : Les écrans aérauliques (1) (Sous caisse).
Brancher l’outil de diagnostic .
Actionner la pompe d’additif ; À l’aide d’un outil de diagnostic.
NOTA : La procédure "pièce de rechange" permet d’amorcer le circuit.
