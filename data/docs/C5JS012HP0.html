C5JS012HP0Déshabillage - habillage : Pare-chocs arrière
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Outillage
outil Référence Désignation
Figure : e5ag02mt
 [1350-ZZ] Outils de dégarnissage
2. Opération préliminaire
Débrancher la batterie de servitude .
Déposer :
  • Le pare-chocs arrière
  • Les capteurs de proximité
  • Les feux antibrouillard arrière
3. Déshabillage
3.1. Faisceau électrique
Figure : c5js07bd
Déclipper le faisceau électrique (1) (en "a") ; À l’aide de l’outil [1350-ZZ].
Dégager le faisceau électrique (1) (en "b").
Déposer le faisceau électrique (1).
3.2. Jonc chromé
Figure : c5js07cd
Déposer les écrous (3).
Déposer le jonc chromé (2).
3.3. Bandeau inférieur
Figure : c5js07dd
Déposer les agrafes (en "d").
Déclipper le bandeau inférieur (4) de pare-chocs (en "c") ; À l’aide de l’outil [1350-ZZ].
Déposer le bandeau inférieur (4) de pare-chocs.
3.4. Trappe d’accès
Figure : c5js07ed
Déclipper la trappe d’accès (5) (en "e") ; À l’aide de l’outil [1350-ZZ].
Déposer la trappe d’accès (5).
3.5. Supports de capteurs de proximité de pare-chocs
Figure : c5js0fcd
Décoller les supports de capteurs de proximité (6) (en "f").
Nettoyer la surface d’appui et de collage de l’adhésif avec le dégraissant indice "J1".
4. Habillage
4.1. Supports de capteurs de proximité de pare-chocs
Figure : c5js0fed
ATTENTION : La peau côté intérieur de pare-chocs arrière ne doit pas être peinte.
NOTA : La température ambiante doit être comprise entre 18 et 35 °C.
Coller l’adhésif (7) sur le support de capteur de proximité (6).
Centrer le jonc (8) sur le capteur de proximité (9).
Reposer le capteur de proximité (9) sur le support de capteur de proximité (6).
Présenter - Centrer : Le support de capteur de proximité (6).
Coller le support de capteur de proximité (6) (Exercer une pression constante pendant 5 à 7 secondes).
Procéder à l’identique pour les autres capteurs de proximité.
4.2. Opérations complémentaires
Procéder dans l’ordre inverse des opérations de déshabillage.
Reposer :
  • Le pare-chocs arrière
  • Les feux antibrouillard arrière
Rebrancher la batterie de servitude .
Vérifier le fonctionnement des différents équipements.
