  • Le pare-boue avant gauche
  • Le déflecteur d’air
  • Le résonateur d’air
Déclipper le boîtier porte-fusibles  (selon montage).
Déposer :
  • Le couvercle de bac à batterie de servitude (selon équipement)
  • La batterie de servitude

Déconnecter le connecteur (en "a") (selon montage).

  • Le bac à batterie de servitude (1)
  • Le support bac à batterie de servitude (selon équipement)
Figure : b2cg0fed
Déconnecter le connecteur modulaire  (en "b").
Déposer les vis (2).
Figure : b2cg0ffd
Extraire le connecteur 3 voies jaune "c" du connecteur modulaire  (en "b").
Dégrafer le faisceau électrique du capteur de vitesse d’entrée de boîte de vitesses (4).
Déposer :
  • La vis (3)
  • Le capteur de vitesse d’entrée de boîte de vitesses (4)
