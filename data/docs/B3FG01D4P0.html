B3FG01D4P0Dépose - repose : Étrier de frein avant
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Outillages
Un presse-pédale.
Pince de type FACOM D60A.
2. Dépose
Placer le presse pédale sur la pédale de frein, afin d’atténuer l’écoulement du liquide de frein lors du désaccouplement des tubes de frein.
Débloquer les vis de roue avant.
Lever et caler le véhicule, roues avant pendantes.
Déposer :
  • Les vis de roue avant
  • La roue avant
Figure : b3fg0cdd
ATTENTION : Veiller à ne pas vriller le flexible de frein avant.
Désaccoupler le raccord flexible  (en "a") (Prévoir l’écoulement du liquide de frein).
NOTA : Obturer la canalisation de frein.
Dégager le flexible de frein avant de son support (en "b").

3. Nettoyage
IMPERATIF : Ne pas utiliser d’air comprimé pour nettoyer les freins.
3.1. 1ère possibilité
Nettoyer le disque et l’étrier de frein ; À l’aide d’un produit nettoyant frein recommandé.
Laisser égoutter et sécher.
Essuyer le disque et l’étrier de frein ; Essuyer à l’aide d’un chiffon papier.
3.2. 2ème possibilité
Utiliser un appareil de dépoussiérage homologué par le constructeur .
4. Contrôle
ATTENTION : Aucune trace de graisse, d’huile, de lubrifiant n’est tolérée sur les garnitures des plaquettes de frein.
Contrôler visuellement :
  • L’étanchéité autour du piston d’étrier de frein
  • Le bon état et l’ajustement parfait des soufflets de protection
  • L’usure des disques de frein
Remplacer les pièces défectueuses.
5. Repose
ATTENTION : Respecter les couples de serrage.
Couples de serrage :
  • Système de freinage
  • roues
Repousser le piston à fond dans son logement à l’aide d’une pince de type FACOM D60A.
NOTA : Intercaler une cale entre la pince type FACOM D60A et la plaquette pour repousser le piston à fond dans son logement.
5.1. Montage TRW
ATTENTION : Lors de chaque dépose, remplacer systématiquement les vis (9) ; Nettoyer les trous taraudés des fixations des vis (9) dans les pivots.
Reposer :
  • Le support d’étrier de frein (10)
  • Les vis neuves préenduites (9)
  • Les plaquettes de frein (8)
ATTENTION : Lors de chaque dépose, remplacer systématiquement les vis (6).
