2. Repose
ATTENTION : Respecter les couples de serrage .
Figure : b1hg166d
ATTENTION : Vérifier l’état du joint d’étanchéité (9) ; Le remplacer si nécessaire.
Mettre en place :
  • Le joint d’étanchéité (9) sur le boîtier doseur d’air admission (8)
  • Le boîtier doseur d’air admission (8)

  • Serrer les fixations (4) à la main ; Le support (5) doit être plaqué et libre en translation
  • Serrer au couple les vis (7)
  • Serrer au couple les vis (6)
  • Serrer les fixations (4) au couple

  • Les tuyaux de vide (3) (en "c")
  • Le raccord d’air admission (2)

Connecter :
  • Les capteurs de doseurs d’air admission (en "a")
  • Le capteur de pression/température d’air d’admission  (en "b")
ATTENTION : Retirer la protection sur le radiateur de refroidissement.
