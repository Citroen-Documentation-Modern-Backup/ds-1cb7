2. Opérations préliminaires
Débrancher la batterie .
Déposer :
  • Le pare-chocs avant
  • Les feux de brouillard avant
  • Les lave-projecteurs
  • Les capteurs de proximité
3. Déshabillage
Déposer la plaque de police .
3.1. Faisceau électrique
Figure : c5js076d
Déclipper : Le faisceau électrique (1) ( en "a") ; À l’aide de l’outil [1350-ZZ].
Déposer : Le faisceau électrique (1).
3.2. Emblème
Figure : c5js077d
Déclipper : L’emblème (2) (en "b").
Déposer : L’emblème (2).
3.3. La grille de pare-chocs avant
Figure : c5js078d
Araser les points de fixation de la grille supérieure de pare-chocs avant (3) (en "e").
Déclipper : La grille supérieure de pare-chocs avant (3) ( en "c", "d","f") ; À l’aide de l’outil [1350-ZZ].
Déposer : La grille supérieure de pare-chocs avant (3).
3.4. Grille supérieure de pare-chocs avant
Figure : c5js079d
Déclipper : La grille inférieure de pare-chocs avant (4) (en "h") ; À l’aide de l’outil [1350-ZZ].
Déposer : La grille inférieure de pare-chocs avant (4).
4. Habillage
Procéder dans l’ordre inverse des opérations de déshabillage.
ATTENTION : Utiliser la mallette de réparation soudage plastique et bouterollage (Voir catalogue équipement des marques).
NOTA : Se servir des pattes de bouterollage de remplacement pour reposer la grille supérieure de pare-chocs avant (3).
Reposer :
  • Les capteurs de proximité
  • Les lave-projecteurs
  • Les feux de brouillard avant
  • Le pare-chocs avant
Rebrancher la batterie.
Vérifier le fonctionnement des différents équipements.
