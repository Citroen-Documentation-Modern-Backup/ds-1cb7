 [1350-ZZ] Outils de dégarnissage
2. Dépose
2.1. Capot moteur
Figure : c4ag1ocd
Déclipper : Le raccord (4) (en "a") ; À l’aide de l’outil [1350-ZZ].
Désaccoupler la durit (1) du raccord (4).
ATTENTION : Deux opérateurs sont nécessaires.
Déposer :
  • Les vis (3)
  • Le capot moteur (2)
2.2. Bras d’articulation de capot moteur
Figure : c4ag1odd
Déposer : Les enjoliveurs de montant de baie de pare-brise .
Desserrer les vis (7).
Écarter légèrement : Les ailes avant (Pour faciliter l’accès).
Dégager les joints d’étanchéité (8).
Déposer :
  • Les vis (6)
  • Les bras d’articulation de capot moteur (5)
3. Repose
Procéder dans l’ordre inverse des opérations de dépose.
Serrer :
  • Les vis (6) à 1,5 m.daN
  • Les vis (3) à 1,5 m.daN
Effectuer le réglage des jeux et affleurements .
Vérifier le fonctionnement des différents équipements.
