B3BG013ZP0Dépose - repose : Amortisseur arrière
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Outillage
Outils amortisseur (Types FACOM D83C).
2. Dépose
ATTENTION : La dépose repose des amortisseurs de suspension s’effectue côté par côté.
Desserrer le frein de stationnement.
Lever et caler le véhicule, roues arrière pendantes.
Déposer :
  • La roue arrière
  • Le cache de traverse arrière (Suivant équipement)
Figure : b3bg05zd
Placer une chandelle hydraulique (en "a").
Comprimer légèrement le ressort de suspension.
Déposer :
  • L’écrou (1)
  • La vis (2)
Figure : b3bg0axd
Déposer :
  • Les vis (3)
  • Les agrafes (4)
Écarter le pare-boue .
Figure : b3bg0b0d
Déposer :
  • Les vis (5)
  • L’amortisseur (6)
Figure : b3bg0b3d
Déposer :
  • L’écrou (7) ; À l’aide des outils type FACOM D83C
  • Le support supérieur (8) de l’amortisseur (6)
  • La butée (9)
3. Repose
ATTENTION : Respecter les couples de serrage.
Couples de serrage :
  • Train arrière
  • roues
Reposer :
  • La butée (9)
  • Le support supérieur (8) de l’amortisseur (6)
ATTENTION : Contrôler l’absence de fuite d’huile de l’amortisseur (6).
Reposer :
  • L’écrou (7) ; À l’aide des outils type FACOM D83C
  • L’amortisseur (6)
  • Les vis (5)
  • La vis (2)
  • L’écrou (1) sans le serrer
  • Le pare-boue
  • Les agrafes (4)
  • Les vis (3)
Décomprimer le ressort de suspension.
Reposer :
  • Le cache de traverse arrière (Suivant équipement)
  • La roue arrière
  • Le véhicule sur ses roues
Mettre le véhicule en assiette de référence.
Serrer l’écrou (1).
