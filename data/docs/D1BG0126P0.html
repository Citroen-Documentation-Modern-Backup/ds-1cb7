D1BG0126P0Dépose - repose : Démarreur
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Dépose
IMPERATIF : Laisser refroidir la ligne d’échappement ; Avant toute intervention sur le démarreur.
Mettre le véhicule sur un pont élévateur.
Débrancher la batterie .
Figure : b1bg05od
Dévisser : Le collier ((1)).
Déclipper : Le résonateur (5).
Déposer :
  • Le résonateur (5)
  • Le raccord d’entrée d’air (2)
Écarter le boîtier porte-fusibles (4).
Déposer :
  • Le cache-style batterie (3)
  • La protection sous moteur
  • Le flexible d’échappement
Figure : d1bg003d
Déconnecter le connecteur  (en "a").
Déposer :
  • L’écrou (7)
  • Les vis (6)
  • Le démarreur (8) (Sortir le démarreur par le dessous de la boîte de vitesses)
2. Repose
ATTENTION : Respecter les couples de serrage .
ATTENTION : Vérifier la présence de la goupille de centrage .
Reposer :
  • Le démarreur (8)
  • Les vis (6)
  • L’écrou (7)
Connecter le connecteur  (en "a").
Reposer :
  • Le flexible d’échappement
  • La protection sous moteur
  • Le cache-style batterie (3)
  • Le boîtier porte-fusibles (4)
  • Le raccord d’entrée d’air (2)
  • Le résonateur (5)
  • Le collier (1)
Rebrancher la batterie.
ATTENTION : Réaliser les opérations à effectuer après un rebranchement de la batterie.
