B3FG01D5P0Dépose - repose : Capteur gyromètre / accéléromètre
AVEC SYSTEME ESP
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Outillage
Un outil de diagnostic.
2. Dépose
Débrancher la batterie .
Pour les véhicules équipés d’un frein de stationnement mécanique : Déposer la console centrale .
2.1. Véhicules équipés d’une boîte de vitesses mécanique / manuelle
Figure : b3fg12rd
Déclipper : Le soufflet de levier de vitesses (1).
Déclipper et déposer : L’enjoliveur supérieur de console centrale (2).
2.2. Véhicules équipés d’une boîte de vitesses mécanique ou pilotée
Figure : b3fg12ud
Déposer :
  • Le cache (5)
  • La vis (6)
  • Le sélecteur de vitesses (3)
Déclipper et déposer : L’enjoliveur supérieur de console centrale (4).
Figure : b3fg12vd
Déconnecter le connecteur  (en "a").
Déposer :
  • Les vis (8)
  • La commande de sélection de vitesses (7)
3. Dépose (suite)
Figure : b3fg12yd
Déposer les écrous (9).
Déconnecter le connecteur ( en "b").
Déposer : Le capteur gyromètre-accéléromètre (10).
4. Repose
ATTENTION : Respecter les couples de serrage .
ATTENTION : Tout capteur gyromètre-accéléromètre (10) ayant subi un choc doit être remplacé.
NOTA : Respecter le sens de montage du capteur gyromètre-accéléromètre (10) : Connecteur vers l’arrière du véhicule.
Reconnecter le connecteur ( en " b ").
Reposer :
  • Le capteur gyromètre-accéléromètre (10)
  • Les écrous ((/))
4.1. Véhicules équipés d’une boîte de vitesses mécanique ou pilotée
Reposer :
  • La commande de sélection de vitesses (7)
  • Les vis (8)
Connecter le connecteur  (en "a").
Clipper : L’enjoliveur supérieur de console centrale (4).
Reposer :
  • Le sélecteur de vitesses (3)
  • La vis (6)
  • Le cache (5)
4.2. Véhicules équipés d’une boîte de vitesses mécanique / manuelle
Clipper :
  • L’enjoliveur supérieur de console centrale (2)
  • Le soufflet de levier de vitesses (1)
5. Repose (suite)
Pour les véhicules équipés d’un frein de stationnement mécanique : Reposer la console centrale .
Rebrancher la batterie.
ATTENTION : Réaliser les opérations à effectuer après un rebranchement de la batterie.
À l’aide d’un outil de diagnostic ; :
  • Effectuer une calibration du capteur gyromètre-accéléromètre
  • Effectuer une lecture et un effacement des codes défauts
